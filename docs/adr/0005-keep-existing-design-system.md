# ADR-0005: حفظ دیزاین‌سیستم موجود، بدون مهاجرت به Tailwind

**Date**: 2026-11-07
**Status**: accepted
**Deciders**: کارفرما (انتخاب «ب + ج»)، تیم اجرا

## Context

دیزاین فعلی تأیید شده بود: پالت قهوه‌ای تیره، تایپوگرافی وزیرمتن + Instrument Serif،
حس «برشته‌کاری تخصصی». پیشنهاد بازطراحی، مهاجرت به Tailwind/DaisyUI و بازنویسی
کامپوننت‌ها را داشت. کارفرما این را رد کرد: «از صفر کد نزن».

## Decision

دیزاین‌سیستم موجود در `app/globals.css` می‌ماند. کتابخانه‌های موجود و کامپوننت‌های
مرجع مستقیماً وارد می‌شوند؛ هیچ مهاجرت فریم‌ورک CSS و هیچ بازنویسی از صفر انجام نمی‌شود.

## Alternatives Considered

### گزینه ۱: مهاجرت به Tailwind + DaisyUI
- **Pros**: سرعت توسعه‌ی بعدی، اکوسیستم بزرگ.
- **Cons**: بازنویسی کل لایه‌ی استایل و رگرسیون بصری در ۵۸ صفحه؛ از دست رفتن
  جزئیات تایپوگرافی فارسی که با دست تنظیم شده بود.
- **Why not**: دستور صریح کارفرما و ریسک بصری بالا بدون سود برای این مرحله.

### گزینه ۲: بازطراحی کامل از صفر
- **Pros**: آزادی کامل.
- **Cons**: همه‌چیز تأییدشده را دور می‌ریخت؛ زمان و بودجه بی‌دلیل مصرف می‌شد.
- **Why not**: صریحاً رد شد.

## Consequences

### Positive
- صفر رگرسیون بصری؛ ۵۸ صفحه‌ی استاتیک بدون تغییر ساختاری ماند.
- حرکت و افکت‌های موجود حفظ شد.

### Negative
- استایل‌ها CSS خام هستند؛ برای کامپوننت جدید باید همان الگوها را دنبال کرد.

### Risks
- **ریسک**: اضافه شدن استایل پراکنده و واگرایی.
  **کاهش**: تغییرات فقط در `app/globals.css` و با توکن‌های موجود؛ گیت
  `scripts/check-export.mjs` و اسکرین‌شات‌های `screenshots/` به‌عنوان مرجع بصری.
