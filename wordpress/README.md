# مهاجرت به وردپرس + ووکامرس

این پوشه خروجی مهاجرت است. ظاهر و داده‌ی سایت Next.js حذف نمی‌شود؛ هر دو منبع، از یک
فایل داده (`data/products.ts`) تغذیه می‌شوند.

```
migration/woocommerce-products.csv   ← ۵۳ محصول متغیر + ۷۲ تنوع
wordpress/vikak-child/               ← چایلد-تم با دیزاین ویکک
  style.css      (هدر تم)
  functions.php  (فونت، CSS، نرخ کیلویی، اعداد فارسی، تریست‌استرپ)
  assets/vikak.css
  assets/fonts.css + fonts/*.woff2   (وزیرمتن، self-host)
```

## ۱. پیش‌نیاز

- وردپرس ۶.۵+ روی هاست ایرانی (PHP 8.1+، MySQL 5.7+ / MariaDB 10.4+)
- ووکامرس
- یک تم پایه‌ی سبک؛ پیشنهاد: **Storefront** یا **Blocksy** (چایلد-تم روی `storefront` تنظیم شده؛ اگر
  تم دیگری می‌خواهید فقط مقدار `Template:` در `style.css` را عوض کنید)
- افزونه‌های پرداخت/ارسال: **زرین‌پال** (یا آیدی‌پی)، **پست/تیپاکس**، **پیامک کاوه‌نگار** (اختیاری)

## ۲. زبان و راست‌به‌چپ

1. Settings → General → Site Language: **فارسی**
2. تاریخ شمسی: افزونه‌ی **WP-Persian** یا **Jalali**
3. اعداد فارسی در قیمت‌ها از `functions.php` انجام می‌شود (فیلتر `wc_price`)؛ اگر افزونه‌ی دیگری
   هم این کار را می‌کند، آن فیلتر را حذف کنید تا رقم‌ها دوباره تبدیل نشوند.

## ۳. نصب تم

```bash
cd wp-content/themes
# پوشه vikak-child را از این ریپو کپی کنید
cp -r /path/to/Vikak-site/wordpress/vikak-child .
```

بعد در پیشخوان: Appearance → Themes → **Vikak Child** → Activate.

## ۴. ایمپورت محصولات

WooCommerce → Products → **Import** → انتخاب `migration/woocommerce-products.csv`:

- ستون `ID` از قبل تعیین شده (۱۰۰۰+ برای محصول، ۵۰۰۰+ برای تنوع) تا اجرای دوباره رکورد تکراری نسازد
  — **گزینه‌ی «Update existing products» را فعال کنید**
- ستون `Weight (kg)` برای محاسبه‌ی نرخ کیلویی و هزینه‌ی ارسال استفاده می‌شود
- تصاویر با URL مستقیم گیت‌هاب ایمپورت می‌شوند؛ پس از ایمپورت، آن‌ها را با عکس واقعی بسته‌ها
  جایگزین کنید (Media → عکس → ضمیمه به محصول)
- دسته‌بندی‌ها خودکار ساخته می‌شوند: `قهوه` + دسته‌ی رست هر محصول

پس از ایمپورت، یک بار: WooCommerce → Status → Tools → **Regenerate product lookup tables**.

## ۵. پرداخت

1. درگاه (زرین‌پال) را نصب و کلید مرچنت را وارد کنید
2. WooCommerce → Settings → Payments → **Zarinpal** → Enable
3. تست با مبلغ کم (۱٬۰۰۰ تومان) روی حالت sandbox اگر درگاه دارد
4. قوانین ارسال: WooCommerce → Settings → Shipping → منطقه‌ی «ایران» → روش «پست پیشتاز»
   با هزینه‌ی وزن‌محور (وزن‌ها به کیلوگرم ایمپورت شده‌اند)

## ۶. آنچه باید بعد از ایمپورت دستی تنظیم شود

- [ ] شماره تماس، نشانی و شبکه‌های اجتماعی واقعی (در تم پایه → Customizer → Footer)
- [ ] عکس‌های واقعی محصول (فعلاً تصاویر عمومی پروژه)
- [ ] متن صفحات «درباره» و «پرسش‌های متداول» (از `app/about/page.tsx` و `app/faq/page.tsx` قابل
      کپی است)
- [ ] لوگو (`public/images/icon.svg` نقطه‌ی شروع است)
- [ ] قالب ایمیل ووکامرس به فارسی و با رنگ‌های ویکک

## ۷. چه چیزی از دیزاین فعلی حفظ می‌شود و چه چیزی نه

| حفظ می‌شود | از دست می‌رود |
|---|---|
| پالت رنگ، تایپوگرافی وزیرمتن | انیمیشن‌های Framer/Lenis هیرو |
| کارت محصول، دکمه‌ها، فرم‌ها | صفحه‌ی هیرو با ترکیب‌بندی اختصاصی |
| صفحه‌ی محصول دوستونه با نرخ کیلویی | سبد خرید دراور (ووکامرس صفحه‌ی خودش را دارد) |
| اعداد فارسی و قیمت شفاف | سرعت استاتیک (وردپرس + ووکامرس سنگین‌تر است) |

اگر خواستید دقیقاً همان هیرو و دراور حفظ شود، راه درست این است که **وردپرس فقط به‌عنوان بک‌اند**
استفاده شود (WPGraphQL + همان فرانت Next.js) — بگویید تا آن مسیر را هم آماده کنم.
